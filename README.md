# BioCak

### *_BioCak_* is a bioinformatics toolkit for processing nucleotide and for filtering reads from a file according to specified parameters.

Author:
    Software: Alisa Senko alisasenko@gmail.com

Пакет выполнялся в рамках обучения и выполняет базовые манипуляции в обработке нуклеиновых кислот.
